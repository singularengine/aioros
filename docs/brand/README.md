# Brand

The Aioros mark is a golden arrow at light speed: an arrowhead flying up and to the right, with the streaks of its flight converging behind it. It stands for the framework's speed (Traced Render Compilation serves pages with almost no work per request) and for the name's Sagittarius, without any artwork from *Saint Seiya*, whose rights belong to Toei and Masami Kurumada. Chosen with the user on (concept H3, "light speed").

## Files

| File | Use |
|---|---|
| `aioros-mark-dark-bg.svg` | The mark on dark backgrounds |
| `aioros-mark-light-bg.svg` | The mark on light backgrounds (a deeper gold for contrast) |
| `aioros-mark-mono.svg` | One color (`currentColor`): print, stamps, terminals |
| `aioros-logo-dark-bg.svg`, `aioros-logo-light-bg.svg` | The mark with the wordmark |
| `aioros-icon.svg` | App icon and large favicons (64 px and up) |
| `aioros-icon-small.svg` | Favicons at 32 and 16 px: one streak, a larger arrowhead |

The wordmark is set in Sora 700 (SIL Open Font License). The logo files use it as live text; convert it to outlines before using them where Sora is not installed.

## Palette

| Color | Hex | Role |
|---|---|---|
| Night | `#0E1626` | Background, wordmark on light backgrounds |
| Gold | `#FFC24B` | Streaks on dark backgrounds |
| Light gold | `#FFD983` | Arrowhead on dark backgrounds |
| Deep gold | `#D98E1C` | Arrowhead on light backgrounds |
| Ivory | `#F2EFE8` | Wordmark on dark backgrounds |

## Rules

- Keep the arrow pointing up and to the right; do not rotate, mirror or recolor it outside the palette.
- Leave clear space around the mark of at least a quarter of its width.
- Below 64 px use `aioros-icon-small.svg`: the five streaks blur at small sizes.
